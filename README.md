# Will You Go On A Date With Me? 💖

An interactive, customizable, and aesthetic date proposal web application.

## Features
- 🌐 Fully customizable texts, dates, foods, and flowers via a secret admin panel
- 🌍 Multi-language support (English, Russian, Ukrainian)
- 🎨 Beautiful minimalist UI with smooth animations
- 🎶 Ambient background music and confetti on success
- 🗄️ JSON-based configuration storage
- 📱 Responsive design

## Tech Stack
- **Frontend:** Next.js (App Router), React, Tailwind CSS, i18next, Framer Motion
- **Backend:** NestJS, TypeScript
- **Storage:** Local JSON files (No database required)
